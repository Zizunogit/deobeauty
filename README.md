# DeoBeauty · experiência do site

Materiais navegáveis da proposta de experiência para a loja deobeauty.me, publicados pelo GitHub Pages (branch `main`, pasta `/ (root)`).

| Endereço | O que é |
|---|---|
| `/` | Página inicial com os dois materiais |
| `/review/` | **De/para do site**: o site de hoje e o site proposto, lado a lado, com o placar da análise de 13/11/2026 e o PDF para baixar (`review/DeoBeauty-de-para-do-site.pdf`) |
| `/checkout/` | **Checkout rápido**: protótipo navegável da compra sem cadastro (sacola, contato, entrega, pagamento e pedido confirmado). Detalhes em `checkout/README.md` |

Tudo é estático: HTML, CSS e JavaScript, sem etapa de build. O arquivo `.nojekyll` fica na raiz.

Protótipos de estudo de UX/UI. Marca, fotos de produto e textos são da DeoBeauty e não estão liberados para outros usos.
